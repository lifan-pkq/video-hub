# 文字与轻效果备忘（v1）

这是 2026-11-18 剪辑学习后收进仓库的实现约束，不是剪映或抖音的官方规格，也不是陈泽个人风格。

- 智能剪辑里的文字和轻效果默认关闭。关闭后不加成片样式。口播字幕烧不烧，由单独的原片字幕选择决定，不靠文字效果开关。
- 原片字幕有四个新选项：还不确定、原片已有字幕、不要另加字幕、烧录转写字幕。前三个不把转写烧进画面。没有自动识别画面里已有的字幕，也不擦原画面像素。旧任务没传这个字段时，仍按当时会烧录转写的方式处理。
- 口播字幕来自转写草稿，角色是引语，必须能改。核对后的文字和转写草稿分开保存，重试不会用新的转写盖掉已核对的句子。标题和旁注是编辑加的说明，不是原话，也不能当成已核对的引语。
- 本机转写默认用 small，语言锁定中文。缓存按模型和编码参数分开。请求的模型加载失败不会改用更小的模型再报成功。较快的 tiny 或 base 会标明不是标准精度。
- 不内置、不抽取剪映、CapCut 或抖音的字体、贴纸、特效、音效、音乐和模板。原声默认保留。没有新增音轨。
- 边距和字号是本项目的默认值，可以改样式，不是官方安全区像素。
- 中文行首标点靠我们自己插入换行来避开，再交给 libass 按不自动折行烧录。这不是 libass 的禁则，也没有宣称通过 GB/T 15834。
- 每条短视频仍是原片上的一段连续画面。重叠转场会改成片时长（两段各 2 秒、重叠 0.4 秒应为 3.6 秒），当前导出没有做这种转场。画面淡入淡出不裁短时长。
- 字体要先检查文件和字符覆盖。FFmpeg 返回 0 不能当成没有缺字或没有退回别的字体。
