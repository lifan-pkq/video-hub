# Video Hub 实用剪辑与智能分析改造设计

## 目标
将现有单轨拼接器升级为可精确截断、可撤销、可恢复草稿的实用剪辑工具；让 AI 建议可逐条控制，并用真实音频数据支持停顿删除。保留 React、FastAPI、FFmpeg 和现有 API 的兼容行为。

## 范围
包含单视频/多视频单轨剪辑、预览、AI 语音分析、时间线应用和导出。不包含多轨、转场、特效、滤镜、字幕烧录、云端项目协作。

## 手动编辑模型
- `EditorClip` 保留 `videoId/fileUrl/srcDuration/trimStart/trimEnd/start/end`。
- `splitClip(clips, clipId, timelineTime)` 仅在播放头严格位于某片段内部且两侧均不少于 0.3 秒时截断；源入点换算为 `trimStart + timelineTime - start`，左右片段获得不同 id。
- 删除左侧/右侧以播放头所在片段为边界：先截断，再删除对应一侧；若播放头位于片段边缘，按相邻完整片段处理，不产生零长度片段。
- 所有操作经过统一命令层并重新 `pack`，不允许负时长、越界或片段重叠。
- 复制片段插入所选片段之后；精确入点/出点限制在源时长内且最短 0.3 秒。
- 时间线缩放只改变显示，不改变源时间。

## 历史、快捷键与草稿
- 每次有效操作记录一个历史快照；拖动排序/边缘裁剪只在结束时入栈，连续指针移动不入栈。
- 撤销/重做只覆盖时间线和标题，不恢复已删除的视频文件，不撤销已发起的后端导出任务。
- 新操作清空 redo；播放头移动、选中、预览播放不入历史。
- 快捷键：`S` 截断、Delete 删除、Space 播放、左右键 1 秒、Shift+左右键 5 秒、Ctrl/Cmd+Z 撤销、Ctrl/Cmd+Shift+Z 或 Ctrl/Cmd+Y 重做；输入控件聚焦时不拦截。
- 草稿按工作区保存在 localStorage，只包含视频元数据引用、裁剪点和标题，不包含 Cookie/令牌。加载时校验视频仍存在且区间有效；损坏草稿忽略并提示。
- 提供“清空时间线”确认；导出成功后保留草稿，便于继续修改。

## 预览
- 预览始终使用当前时间线的源片段和源时间；截断/裁剪/撤销后暂停并同步到正确帧。
- 缓冲时播放头暂停，恢复后继续；播放失败显示可重试错误。
- AI 建议预览不修改时间线：点击建议后跳到对应源视频区间并播放短预览，退出建议预览恢复原播放头。

## AI 分析
- 保留 faster-whisper 本地转写和现有 intro/outro/ad LLM 分析。
- 新增可选 `silence`：FFmpeg `silencedetect` 生成实际静音区间，默认阈值 -35dB、最短 0.6 秒；结果附上来源和原因，不依赖 LLM 猜测。
- 新增 `repeat`：先通过转写文本找完全/高相似重复句作为候选，再让 LLM 判断是否为无信息价值的重复、口头禅；没有候选时不额外请求。
- 长转写按时间/字符预算分块，块间保留少量上下文；每块只能返回当前块范围内的区间，再统一校验、截断、合并。
- API 兼容旧 `video_ids/kinds/custom_prompt`，新增可选参数采用默认值，旧客户端行为不变。
- 建议项包含稳定 id、视频 id、start/end/kind/reason/source；`keep` 仍根据选中的 waste 计算，后端默认返回全部建议的 keep 以兼容旧客户端。
- 前端每条建议默认选中，可单独取消、编辑起止时间、预览；类型和原因清晰展示。
- 应用只合并选中的建议：与当前每个手动片段的源区间求差集，未涉及部分原样保留；不重建整个时间线。应用操作可用统一撤销恢复。
- 错误区分转写失败、AI 服务失败、返回解析失败；已有部分结果时明确显示，不静默当作“无建议”。

## 组件结构
- `features/editor/model.ts`：纯片段操作、校验、区间差集、草稿序列化。
- `features/editor/useEditorHistory.ts`：历史与快捷键状态。
- `features/editor/EditorPreview.tsx`：预览播放及建议预览。
- `features/editor/EditorTimeline.tsx`：时间线、选中、精确裁剪和工具栏。
- `features/editor/AiAnalysisPanel.tsx`：选项、任务状态、建议勾选/编辑/预览。
- `pages/EditorPage.tsx`：组合、数据加载、草稿恢复和导出。
- 后端 `services/ai_edit.py` 负责转写、分块、LLM 和区间清洗；新增独立音频分析模块，避免继续膨胀。

## 测试与验收
- 后端 unittest：静音解析、重复候选、长文本分块、无效/重叠区间、旧 API 兼容。
- 前端无测试框架，不新增依赖；使用浏览器验证截断、左右删除、复制、精确时间、撤销/重做、快捷键、草稿恢复、缩放。
- 用模拟 AI 任务验证逐条勾选、编辑、预览和应用后手动片段保留；用真实临时媒体验证 FFmpeg 导出区间和入库。
- 覆盖 320px、1024px、桌面布局，键盘操作、空/加载/错误状态和 reduced-motion。
- 全量后端 unittest、compileall、前端生产构建、Docker 配置检查必须通过。

## 非目标与约束
- 不自动发布、不覆盖原视频、不删除用户媒体。
- 不上传视频文件给 LLM；仅发送转写字幕及用户自定义提示，静音检测在本地完成。
- 不增加新的前端框架或状态管理依赖。
